HEIGHTLoss

Lower height represents a lower loss: a better value for this simplified training example.

DOWNHILL DIRECTIONGradient

The gradient describes how loss changes around the current parameter value. Training moves in the opposite direction.

STEP SIZELearning rate

The learning rate scales how far the parameter moves on each update.

Try three experiments: use a tiny step, a middle step, and a huge step. Tiny steps need many updates. A reasonable step can descend efficiently. A very large step can jump to bad locations instead of settling near the minimum.
